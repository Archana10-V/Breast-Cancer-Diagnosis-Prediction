# Breast-Cancer-Diagnosis-Prediction

Breast cancer diagnosis prediction using Machine Learning, Flask, and Docker.

## Overview

This project uses a Machine Learning model to predict breast cancer diagnosis from input features. A Flask API provides predictions, and Docker makes the application easier to run in a container.

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Flask
* Docker
* Git and GitHub

## How to Run

1. Install the required dependencies:
   `pip install -r requirements.txt`

2. Run the application:
   `python app.py`

3. Open `http://127.0.0.1:5000` in your browser to check the API.
